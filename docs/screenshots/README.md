# Display screenshots

These captures show the actual built display on localhost on 2026-10-24, using a fresh isolated Chromium context and public NOAA predictions fetched through the app's daily tide API. The same just-captured response was replayed for both images so their curve and events match. The values illustrate that capture date; they are not current observations.

- `display-dark.png`: dark appearance at a 1440 × 1280 CSS-pixel viewport.
- `display-light-mobile.png`: light appearance at a 375 × 812 viewport, captured as the full scrollable page.

Only the page is captured, with no browser chrome, deployment address, Maps key, owner browser profile or private configuration. Device location is seeded from the public station's own coordinates for this capture. The original Tidepin logo, NOAA credit, navigation disclaimer and personal/source credit remain visible.
